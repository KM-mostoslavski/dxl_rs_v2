Model data, each checked on the page:

(a) `protocols: [P1]`. No Protocol Type register (none of the 32 rows); the specification row
"Protocol Type" reads "Half Duplex Asynchronous Serial Communication (8bit, 1stop, No Parity)" (the
serial link, not a DYNAMIXEL protocol). The page body cites only Protocol 1.0: "Please refer to
DYNAMIXEL Protocol 1.0 for more details about Instruction Pack[et]" and "refer to the Status Packet
section for DYNAMIXEL Protocol 1.0". The Protocol 1.0 page lists RX-28 among its products.

(b) `type_info`: `512 / 0 / 1023`, `min_radian: -2.6205530`, `max_radian: 2.6154347`. Page:
"The available position range is 0 to 1,023 (0x3FF) and the per unit value is 0.29 °",
specification "Resolution 0.29°", "Running Degree 0° ~ 300° Endless Turn"; the Goal Position figure
(`/assets/images/dxl/dx/dx_series_goal_position.png`, the same image as AX-12A) labels 0 → 0°,
512 (0x200) → 150°, 1023 (0x3FF) → 300°. Slope 300°/1023 per tick, zero 512 (research R-8:
−512 ticks → −2.6205530 rad, +511 ticks → 2.6154347 rad).

(c) `unit_info` (only values the page gives):
- `Position 0.29 deg unsigned`: "per unit value is 0.29 °", range 0 ~ 1,023.
- `Speed 0.111 rpm signed`: Moving Speed / Present Speed, Joint Mode: "the unit is about
  0.111rpm"; Present Speed 0 ~ 2,047 with "the 10th bit becomes the direction bit". Reviewer
  note: a direction bit (sign and magnitude), as for AX-12A.
- No torque entry: the page gives torque only as "about 0.1%" of the maximum.

(d) `instructions: [(protocol: P1, source: "https://emanual.robotis.com/docs/en/dxl/protocol1/",
list: [Ping, Read, Write, RegWrite, Action, FactoryReset, SyncWrite])]`. On the Protocol 1.0 page,
Ping, Read, Write, Reg Write, Action, Factory Reset and Sync Write carry no product condition;
Reboot ("Supported products : DYNAMIXEL MX-12W(V41), MX-28/64/106(V40), MX(2.0) and X Series
(excluding XL-320)") and Bulk Read ("Supported products : DYNAMIXEL MX, MX(2.0) and X Series
(excluding XL-320)") do not include RX-28.

(e) Mode source: the page lists no `Operating Mode` or `Control Mode` register and does list
`CW Angle Limit` (6, 2, RW, EEPROM) and `CCW Angle Limit` (8, 2, RW, EEPROM). Its "CW/CCW Angle
Limit(6, 8)" section: "The following two modes can be set pursuant to the value of CW and CCW":
Wheel Mode "both are 0", Joint Mode "neither are 0"; Goal Position: "If it is set to Wheel Mode,
Goal Position value is not used." So the table carries neither mode row and no `operating_modes`.

(f) `source: Verified(url: "https://emanual.robotis.com/docs/en/dxl/rx/rx-28/", verified:
"2026-10-28")`.

`"rx_28": "https://emanual.robotis.com/docs/en/dxl/rx/rx-28/"` added to `PAGES` in
`control_tables/emanual.py`.

Model number on the page: the Model Number row (0, 2, R, EEPROM) has Initial Value **28**; name
"RX-28" (page title and heading).
