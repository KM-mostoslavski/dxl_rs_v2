# T2 X330 group (T068): 12 tables

T1 findings: `t1-x330.md` (and spec Clarifications 2026-10-29: the `_fw52` tables take
`access`/`area` from the current X330 page with its firmware note applied; "Indirect Address Read"
(180) and "Indirect Data Read" (230 / 214) sat in elided rows, "T2 decides whether they are
renamed or removed").

Decision: **removed**, like the other alias rows. No page lists the names "Indirect Address
Write", "Indirect Data Write", "Indirect Address Read" or "Indirect Data Read"; renaming 180 and
230 to the numbered rows they overlay (Indirect Address 7, Indirect Data 7 on the current table)
would add numbered indirect rows, which T2 does not do (T060, research R-9). Tables stay
`source: Unverified`.

Removed per table: current tables 168 2 "Indirect Address Write", 224 1 "Indirect Data Write",
180 2 "Indirect Address Read", 230 1 "Indirect Data Read"; `_fw52` tables 168 2 "Indirect Address
Write", 208 1 "Indirect Data Write", 180 2 "Indirect Address Read", 214 1 "Indirect Data Read".

Kept in the `_fw52` tables: 208 1 "Indirect Data 1" (diff "only in table" against the current
page, whose Indirect Data 1 is at 224). Source: the page note "Firmware versions prior to V53
support up to 20 Indirect Address/Data items. The address range for Indirect Address is 168 ~
207, and for Indirect Data is 208 ~ 227." (re-read 2026-10-29 on each model page).

Not added: "Startup Configuration" (60) and "Backup Ready" (147), only on the pages, "available
from firmware V45" (same reason as the X430 group, `t2-x430.md`); numbered indirect rows. Mode
row: `Operating Mode` (11, 1, RW, EEPROM) on every page, as the tables; `operating_modes`
unchanged.

Generated effect: `INDIRECT_ADDRESS_WRITE`, `INDIRECT_DATA_WRITE`, `INDIRECT_ADDRESS_READ`,
`INDIRECT_DATA_READ` leave each of the 12 types.
