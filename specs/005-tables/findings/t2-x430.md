# T2 X430 group (T066): 15 tables

T1 findings: `t1-x430.md`.

Rule (research R-14): "Indirect Address Write", "Indirect Data Write", "Indirect Address Read",
"Indirect Data Read" are removed only where the page does not list that name; no page lists any
of them. Page rows read with `emanual.py` (`PAGES`), diffed with `emanual.compare`, before and
after. Tables stay `source: Unverified`.

Other T1 row findings for this group: none to correct. T1 lists two rows the pages have and the
tables lack, "Startup Configuration" (60, 1, RW, EEPROM) and "Backup Ready" (147, 1, R, RAM), "not
added in T1; a later correction". They are **not added in T2**: the T2 rule corrects address, size
or name from the page and adds only a missing mode row, and each page says "Startup Configuration
is available from firmware V45" / "Backup Ready is available from firmware V45", a per-row firmware
condition the table format cannot carry (question for the architect). The numbered indirect rows
only on the page stay out, as in T060. Mode row: `Operating Mode` (11, 1, RW, EEPROM) on every
page, as the tables (T1 confirmed it; the diffs show no mode-row difference); `operating_modes`
unchanged. Diff after: only the 22 numbered indirect rows and the two rows above, "only on page".

Generated effect: `INDIRECT_ADDRESS_WRITE`, `INDIRECT_DATA_WRITE`, `INDIRECT_ADDRESS_READ`,
`INDIRECT_DATA_READ` leave each mapped type of the group (`xw430_t200` is not mapped, so it
changes no generated file).
