## Model data

- Model number: Model Number row Initial Value **320** (research R-11: 320).
- `protocols: [P1]`: no Protocol Type register; "Please refer to DYNAMIXEL Protocol 1.0 …";
  "WARNING : For MX-106(2.0) Protocol, please refer to the MX-106(2.0) Control Table as they are
  different."
- Mode source: no `Operating Mode` register. "Drive Mode (10)" is a register, but its bits are
  "Master/Slave Mode (Dual Joint)" and "Normal/Reverse Mode", not an operating mode; it is not a
  mode source. CW/CCW Angle Limit (6, 8) with the same three-mode text as MX-28/64. No
  `operating_modes`. (Note for the architect: Reverse Mode changes the direction of rotation;
  `type_info` does not model it.)
- `type_info` `2048 / 0 / 4095`, `-3.1415927` / `3.1400587`: Goal Position "0 to 4,095 (0xFFF) is
  available. The unit is 0.088 [°]", Resolution "4096 [pulse/rev]", figure
  `/assets/images/dxl/mx/mx_position.png` (180° = 2048).
- `unit_info`: Goal/Present Position 0.088 deg unsigned; Moving Speed 0.114 rpm signed; Present
  Speed 0.11 rpm signed; Goal Torque 4.5 mA signed ("the unit is 4.5mA", direction bit); Goal
  Acceleration 8.583 deg/s^2 unsigned.
- Page notes as on MX-64: Torque Ctrl Mode Enable (70) makes the actuator ignore Goal Position
  (question in `t2-mx_64_p1.md`); Realtime Tick "available from Firmware v40"; the Multi Turn
  Offset note contradicts the CW/CCW table.
